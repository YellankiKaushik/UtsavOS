# Archived reports and release evidence

This directory preserves dated reports, audit checkpoints, implementation matrices, and owner-action records. Their dates and recorded results remain part of the project history. They describe the repository or hosted application at the checkpoint shown inside each file; they are not current setup, deployment, or public-site instructions.

Use the current [setup guide](../../SETUP.md), [deployment guide](../../DEPLOYMENT.md), [testing guide](../../TESTING.md), [static release verification](../../STATIC_SHOWCASE_RELEASE_VERIFICATION.md), and [hosted-service retirement checklist](../../HOSTED_SERVICE_RETIREMENT_CHECKLIST.md) for present-day guidance.
