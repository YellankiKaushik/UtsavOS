# Historical screenshot classification

These existing images are retained at their original paths to preserve historical links and test evidence:

- `landing-desktop.png`: application landing UI from the earlier development/test checkpoint; no authentication or live-provider evidence is implied.
- `planner-desktop-synthetic.png`: controlled API-fixture browser UI, explicitly marked synthetic. Its reserved synthetic account label is not a real user identity.
- `planner-mobile-synthetic.png`: mobile version of the same fixture-based test; no live authentication/provider claim.

The [archived product gallery](../assets/README.md) preserves imagery of the original full-stack interface with isolated synthetic records. These files are not screenshots of the current public static showcase. Fixture screenshots must never be described as genuine production generation or customer data.
