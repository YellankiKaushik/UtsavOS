# Product media provenance

The images in this directory were captured read-only from https://utsavos.vercel.app on 29 October2026 using an isolated synthetic reviewer/event. They are real application pixels backed by saved planning records, not mocked API payloads or customer data. No new AI generation or planning-data mutation was performed for the captures.

| Image              | What it shows                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| landing.png        | Anonymous product landing page; README hero                                                    |
| overview.png       | Saved synthetic wedding workspace, approved budget and accepted tasks/vendors                  |
| demo-thumbnail.png | Exact copy of overview.png, linked to the owner-supplied verified YouTube walkthrough          |
| dashboard.png      | Loaded workspace usage limits and progress; not a paid subscription                            |
| ai-planning.png    | Saved genuine AI planning output; not a new generation                                         |
| budget.png         | Exact fixed/per-guest estimates at180 guests                                                   |
| timeline.png       | Accepted tasks and dependency relationships                                                    |
| change-impact.png  | Previously approved before/after proposal; current stale/expiry notices intentionally retained |

Account email/avatar are hidden only with capture CSS. Visible data was checked for emails, credentials, cookies, tokens and guest contacts. Synthetic event titles identify test records, not real people. The first capture pass exposed loading/wrong-route states; those were corrected before staging and are not presented as product proof.

[manifest.json](manifest.json) records dimensions/bytes. PNGs are already small lossless screen captures; no lossy recompression or invented visual content was needed. The video itself is not committed and no original-video download is hosted in Git. Owner-authorized UtsavOS captures do not establish a new open-source license for the project or third-party components.

Earlier [docs/screenshots](../screenshots/README.md) images remain for test history and are not the new gallery. Earlier delivered Preview images outside this repository were visually inspected; fresh production captures were chosen instead.
