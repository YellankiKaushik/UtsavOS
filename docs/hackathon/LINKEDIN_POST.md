I built UtsavOS for PromptWars Virtual Challenge5: Celebration & Event Planner.

An event plan changes when the guest count changes. I wanted AI ideas to become something a host can actually work with: editable tasks, budgets and vendor requirements, with a clear explanation of what changes next.

UtsavOS supports weddings, birthdays and community events. Real OpenRouter generation with dots-studio/dots-3-note-preview:free has passed hosted review, selective acceptance and persistence. Direct Gemini support is integrated, but the supplied credential returned401; I am not claiming successful Gemini generation.

The engineering lesson: useful AI needs explicit structured contracts and human review. Financial totals stay deterministic. A150-guest plan with ₹300,000 fixed costs and ₹850 catering per guest totals ₹427,500. At180 guests it becomes ₹453,000, leaving ₹47,000 from ₹500,000. The application previews that impact and requires approval before saving.

OpenAI Codex assisted implementation, debugging, tests and release preparation. The stack includes Next.js, TypeScript, Supabase, Vercel, GitHub Actions, Vitest and Playwright. I have not claimed Antigravity use; organizer clarification about tool eligibility is still pending.
