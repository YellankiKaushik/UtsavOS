# UtsavOS — Celebration & Event Planner

Hosts need a usable plan when guests, suppliers and costs change. UtsavOS supports weddings, birthdays and community events through a persistent workspace rather than a disposable chat transcript.

Users enter event details and preferences, generate a structured AI draft, review assumptions, edit/select records and save useful tasks, vendor categories and budget suggestions. Tasks support deadlines, dependencies, status and event time zones. Suggestions remain unverified; no business availability, quotation, booking or payment execution is invented.

The distinctive flow is AI draft → editable operational records → deterministic change preview → explicit approval. With ₹300,000 fixed costs and ₹850 catering,150 guests total ₹427,500;180 total ₹453,000, leaving ₹47,000 from ₹500,000. PostgreSQL transactions enforce versions, locks, idempotency and history. Model arithmetic is never the financial authority.

The stack is Next.js/React/TypeScript/Zod with Supabase Auth, RLS, PostgreSQL and private Storage.
